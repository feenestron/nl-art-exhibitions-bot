# NL Art Exhibitions Bot

Telegram-бот для группы: раз в две недели, в пятницу утром, публикует подборку выставок
известных художников в музеях и выставочных залах Нидерландов на ближайшие две недели.

Работает целиком на GitHub Actions — сервер не нужен.

```
пятница 9:17   GitHub Actions забирает все временные выставки с museum.nl
  ↓            (~300 музеев) и со страниц нескольких музеев, которых там нет
  ↓            оставляет те, что открываются или закрываются в ближайшие 14 дней
  ↓            Claude отбирает выставки известных художников и пишет пояснения
  →            выпуск сразу уходит в группу
```

## Пример выпуска

> 🎨 **Выставки в Нидерландах**
> 23 октября — 5 ноября
>
> 🆕 **Открываются**
>
> • **Поль Синьяк** — [Signac. Symphony of Colours](#)
> Kunsthal Rotterdam · с 24 октября по 28 февраля 2027
> *Крупнейший за много лет обзор творчества мастера пуантилизма.*
>
> ⏳ **Последний шанс**
>
> • **Шарли Тороп и Пейк Кох** — [Alles of niets](#)
> Museum MORE, Gorssel · до 1 ноября

В разделе «Открываются» — выставки, которые открываются в ближайшие две недели или открылись
после прошлого выпуска. В «Последний шанс» — уже идущие выставки, которые закрываются
в ближайшие две недели. Выставка, объявленная при открытии, может ещё раз появиться
в «последнем шансе» перед закрытием; дважды в одном разделе — никогда.

## Настройка (один раз, ~15 минут)

### 1. Бот и группа
1. В Telegram откройте **@BotFather** → `/newbot`, придумайте имя. Сохраните **токен**.
2. Добавьте бота в группу. Права администратора не нужны, если в группе всем разрешено
   писать сообщения.

### 2. Ключ Claude API
На [console.anthropic.com](https://console.anthropic.com) создайте API-ключ (можно тот же,
что для делфтского бота). Выпуск стоит порядка 10–20 центов: раз в две недели модель
просматривает около сотни кандидатов. Без ключа бот не публикует — отбор «известных»
делает именно модель.

### 3. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `CHAT_ID` | id группы — см. шаг 4 |
| `ADMIN_CHAT_ID` | *необязательно*: ваш личный chat_id, туда бот пишет о сбоях и проблемах с источниками (тот же, что у делфтского бота) |

### 4. Узнать id группы
**Actions → Find chat id → Run workflow**. В итогах запуска (Summary) будет список групп,
куда добавлен бот, с их id вида `-100…`. Если список пуст — удалите бота из группы,
добавьте снова и повторите. Запишите id в секрет `CHAT_ID`.

### 5. Проверка
1. **Actions → Post exhibitions → Run workflow** (по умолчанию отмечен **dry_run**) —
   выпуск появится в Summary запуска и в файле `preview/last_dry_run.md`, в Telegram ничего
   не уйдёт. Там же видны все кандидаты и проблемы с источниками.
2. Чтобы опубликовать сразу, снимите **dry_run** и отметьте **force**.

Дальше всё работает само: каждую пятницу workflow запускается, но публикует только
если с прошлого выпуска прошло две недели. Первый выпуск по расписанию — в ближайшую
пятницу (или ручной запуск с **force**, от него и пойдёт отсчёт).

## Настройки (необязательно)

**Settings → Secrets and variables → Actions → Variables**:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `INTERVAL_DAYS` | `14` | раз во сколько дней выходит выпуск |
| `PERIOD_DAYS` | `14` | на сколько дней вперёд смотреть |
| `POST_HOUR` | `9` | с какого часа (по Амстердаму) можно публиковать; cron в `post.yml` настроен на 9:17 |
| `POST_WEEKDAY` | `4` | день недели (0 — понедельник, 4 — пятница); при смене поправьте cron |
| `MAX_NEW` / `MAX_LAST` | `15` / `10` | максимум пунктов в разделах |
| `MAX_FETCH` | `160` | сколько страниц выставок на museum.nl открывать за запуск |
| `ANTHROPIC_MODEL` | `claude-sonnet-5-5` | модель Claude |

## Источники

Список — в [`sources.yaml`](sources.yaml):

* **museum.nl** (Museumvereniging) — все временные выставки примерно 300 музеев с Museumkaart:
  Rijksmuseum, Van Gogh, Stedelijk, Mauritshuis, Kunsthal, Kröller-Müller, Fotomuseum
  и т. д. Даты начала и конца берутся из структурированных данных страницы каждой выставки,
  ссылка в выпуске ведёт на сайт музея.
* **Отдельные музеи**, которых нет на museum.nl (Voorlinden, H'ART). Страницу
  «Tentoonstellingen» читает Claude и вытаскивает выставки с датами. Добавить свой
  музей — три строки в `sources.yaml`:

  ```yaml
  - name: Museum X
    type: venue_page
    url: https://www.museumx.nl/tentoonstellingen
    venue: Museum X
    city: Utrecht
  ```

Бот соблюдает `robots.txt`, представляется отдельным User-Agent, делает паузу между
запросами к одному сайту и заходит раз в две недели. Состояние (что уже объявляли,
дата последнего выпуска) хранится в `state/state.json` и коммитится workflow.

## Локальный запуск

```bash
pip install -r requirements.txt
ANTHROPIC_API_KEY=... python -m bot post --dry-run   # собрать и напечатать, ничего не отправлять
python -m unittest discover -s tests                  # тесты
```

## Эксплуатация

* **Сбои.** Если запуск упал, бот пишет в `ADMIN_CHAT_ID` ссылку на запуск; GitHub также
  присылает письмо владельцу репозитория. Проблемы с отдельными источниками бот присылает
  туда же после выпуска.
* **Пропущенная пятница.** Если запуск не состоялся, выпуск выйдет в следующую пятницу,
  и дальше отсчёт пойдёт от неё.
* **Автоотключение расписания.** GitHub отключает cron в публичных репозиториях после 60 дней
  без активности; каждый запуск заново включает расписание.
* **Группа стала супергруппой.** У неё меняется id; бот это переживёт и пришлёт
  напоминание обновить `CHAT_ID`.
